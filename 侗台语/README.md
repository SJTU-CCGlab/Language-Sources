## 1  数据概况

例：该数据集收集了学界所调查记录的共19个侗台语语言点的语料，既有境内的侗台语族壮傣语支语言，也有越南、泰国等境外的跨境侗台语族壮傣语支语言。该数据了包括了1158个词汇条目（共2.5万条数据）。该数据集是中文系现代汉语教研室牵头申报的“语言认知与演化跨学科协同研究创新平台”的阶段性成果，目前包含约2.5万多条境内外侗台语族共19个语言点的字音、字形、字义等相关信息。

## 2  数据的意义

侗台语是汉藏语系的重要组成部分。侗台语的现状与历史研究，对于解决汉藏语系、南岛语系等语言，乃至中华民族文明起源的问题，都是关键性的意义。布目前学界关于侗台语的语料集，主要来自《壮侗语族语言简志》（王均1984）、《壮侗语族语言词汇集》（中央民族学院1985）和《侗台语族概论》（梁敏、张均如1996）等。但是这些语言调查报告，主要涉及的是中国境内的语言点，而关于境外侗台语的材料，多付阙如。在这种情况下，制作一个侗台语境内外语言的多点语料库，就显得很有现实意义和学术价值。有鉴于此，本数据集汇总了学界已有的境内外侗台语代表性语言的田野材料，提供了19个方言点的语料，并将其转制成excel格式、可供查询与比较的电子语料库。该数据集不但是侗台语族某个代表性语言内部的详细调查报告，可以帮助我们充分挖掘境内与境外侗台语的异同特点，还可以将其作为范本，接下来制作其他侗台语甚至于汉藏语系内部的布点密集性语料集的参考。

## 3  数据采集和处理方法

本数据集包含1个excel文件（含19个中国境内与境外侗台语方言点名称表、词目序号表[如“陌生”#1159]、汉字词目表[如“陌生”字#1159]、词目英译[如“陌生”为“strange”]、该词在侗台语多个语言点的读音[如龙茗壮语读peek2]）。涉及多个数据字段、字段名、字段名解释和样例值，详见表2。
